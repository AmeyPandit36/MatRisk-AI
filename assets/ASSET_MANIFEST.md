# MatRisk AI asset manifest

All artwork is original local SVG. Colours and geometry follow the dashboard's navy/cyan engineering identity.

| Path | Purpose |
|---|---|
| `brand/matrisk-lockup.svg` | Sidebar wordmark lockup with exact product name MatRisk AI. |
| `brand/matrisk-mark.svg` | Compact standalone geometric lattice mark for compact contexts. |
| `brand/favicon.svg` | Browser/page icon passed to Streamlit. |
| `icons/overview.svg` | Overview module icon, dashboard grid. |
| `icons/materials.svg` | Materials module icon, faceted lattice. |
| `icons/commodity.svg` | Commodity module icon, price series. |
| `icons/infrastructure.svg` | Infrastructure module icon, bridge structure. |
| `icons/esg.svg` | Sustainability module icon, leaf and vein. |
| `icons/models.svg` | Model laboratory icon, measured points and trend. |
| `icons/quality.svg` | Data quality module icon, checked record. |
| `backgrounds/overview-hero.svg` | Quiet grid, abstract nodes, and geometry behind the Overview hero. No data values or scientific structure are encoded. |

The seven icons are integrated in the corresponding page headings. The sidebar uses one persistent native Streamlit radio navigation, without a duplicated icon strip; radio labels retain keyboard and screen-reader behavior.
